# 课程范围

## 学习者

课程面向第一次进入 GitHub、希望运行开源项目并完成首次安全贡献的中文学习者。课程不假设用户熟悉终端、Git、Node.js 或技术英语。

完整学习与毕业任务以桌面电脑为正式支持环境。手机端只承担抖音发现后的项目介绍、第零章阅读和演示预览，不设计在手机上完成 GitHub、终端或本地项目实操的路线。

## 产品闭环

抖音发现项目 → 真实 GitHub 注册或登录 → 阅读仓库指南 → Fork → Clone 或 Codespaces → 安装并运行 → 完成模拟主线 → 回到自己的 Fork 完成毕业练习 → 本地生成分享卡。

第零章发生在真实仓库中。应用内不会替代 GitHub 的登录、账号安全、Fork 或 Clone，也不会伪装验证这些动作。

## 核心能力边界

主线覆盖账号安全、仓库阅读、项目判断、关注方式、Issue、远程同步、Branch、Commit、Push、Pull Request、Review、Merge、Actions、Release 和社区健康文件。毕业任务只在学习者自己的 Fork 中完成。

不覆盖企业组织治理、复杂权限、GitHub API、OAuth、高级 DevOps、复杂冲突实操、付费课程或社区毕业墙。

## 完成定义

- 所有主线路径上的英文 UI 已解释。
- P0/P1 主线覆盖率为 100%。
- 每个 P0 有互动任务并进入结业测试。
- 所有真实操作使用清单自证，不显示“已自动验证”。
- 用户可以独立运行项目，并在自己的 Fork 完成一次 Branch → Commit → Push → PR → Merge。
