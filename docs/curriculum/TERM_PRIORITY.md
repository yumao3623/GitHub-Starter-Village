# 术语权重规则

## P0 核心必会

P0 是完成核心 GitHub 流程不可缺少的概念。每项必须出现在主线、被实际操作或场景判断覆盖，并进入结业测试。毕业时 P0 掌握率必须达到 100%。

当前 P0 集中在 Repository、README、注册登录、Fork、Clone、Branch、Commit、Push、Pull、Pull Request、Issue、Diff、Stage、Merge、Review、Approve、Request changes、Actions、Workflow、Checks、License、本地与远程仓库以及 main。

## P1 高频常用

P1 是普通用户在页面和常见流程中频繁遇到的导航、动作、状态、安全概念与运行术语。每项必须有官方来源并在主线中得到场景化解释，可进入测试但不阻塞毕业。

## P2 扩展认识

P2 收录在可搜索词典和相关章节的支线说明中，不强迫初学者一次记住，也不阻塞毕业。它涵盖 Milestone、合并策略、Artifact、Pages、Wiki 等扩展概念。

## 调整规则

权重由“是否阻塞用户完成本课程范围内的真实任务”决定，不由词频或计划数量决定。调整权重必须同步更新章节、互动、结业题、UI 覆盖与覆盖报告。
