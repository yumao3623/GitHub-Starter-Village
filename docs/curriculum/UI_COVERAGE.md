# 界面英文覆盖

## 覆盖方式

每个章节通过 `uiTerms` 声明学习者必须理解的界面英文。`npm run content:validate` 会检查它们是否能映射到词典条目，并检查引用和重复 ID。

## 旅程覆盖

- 账号：Sign up、Sign in、Username、Profile、Settings、2FA、Passkey、Recovery codes。
- 仓库入口：Repository、Public、README、Code 页签、Code 菜单、Star、Fork。
- 复制运行：Clone、Download ZIP、Codespaces、Node.js、npm install、npm run dev、localhost。
- 仓库判断：Branch、main、Contributors、License、Releases、Tags、Search、Installation、Requirements、Archived。
- 关注：Star、Watch、Notifications、Follow、Fork。
- Issue：Open、Closed、Label、Assignee、Milestone、Comment、Subscribe、good first issue。
- Git：Local/Remote repository、origin、upstream、Fetch、Pull、Push、Sync fork、Changes、Diff、Stage、Commit、SHA。
- PR：New pull request、Base、Compare、Draft、Conversation、Commits、Checks、Files changed。
- Review：Comment、Approve、Request changes、Resolve conversation、Merge 与冲突。
- 自动化与发布：Workflow run、Job、Step、Passed、Failed、Artifact、Release、Tag、Changelog、Pages。
- 社区：CONTRIBUTING、LICENSE、CODE_OF_CONDUCT、SECURITY、Discussions、Wiki 与角色。

GitHub 的按钮位置和措辞会变化。课程依赖英文标签与任务目标，而不依赖像素坐标；修改 UI 文案时必须同步更新词典和核验日期。
