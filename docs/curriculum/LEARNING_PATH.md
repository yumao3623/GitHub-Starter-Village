# 学习路径

## 阶段一：进入新手村

| 章节 | 场景 | 真实或模拟 | 结果 |
| --- | --- | --- | --- |
| 0 | 找到仓库与中文入口 | 真实 GitHub | 认识 Repository、README、Fork、Code |
| 1 | 注册、登录与安全 | 真实 GitHub | 只在官方页面处理凭据，理解 2FA 与恢复方式 |
| 2 | 复制项目 | 真实 GitHub/Desktop/Codespaces | 区分 Fork、Clone、ZIP |
| 3 | 运行游戏 | 本地终端 | 理解 Node.js、npm 与 localhost |

## 阶段二：认识 GitHub

第 4 章建立仓库地图；第 5 章用文档、许可和维护状态判断项目；第 6 章通过场景区分 Star、Watch、Follow、Notifications 与 Fork。

## 阶段三：完成模拟开源贡献

第 7-13 章围绕原创虚构项目 `nightwalk-map` 展开：记录路线错误，理解本地与远程，创建分支，检查 Diff，Commit 与 Push，提出 Pull Request，响应 Review，观察 Actions，完成 Merge，并检查社区健康文件。

应用内每个模拟按钮都标注“游戏模拟”。模拟结果不写入 GitHub。

## 阶段四：真实毕业任务

用户回到自己的 Fork，在 `graduates/practice/` 中新建练习文件，创建分支、Commit、Push，并在自己的 Fork 内创建和合并 Pull Request。该任务默认不向原仓库提交 PR。

## 辅助模式

首次启动为全中文辅助。用户可切换到中英对照、悬停翻译、挑战模式或自由探索。减少中文提示是用户选择，不是进度门槛。
