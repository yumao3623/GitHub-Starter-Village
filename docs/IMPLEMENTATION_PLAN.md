# GitHub 新手村实施计划

最后更新：2026-09-10

## 产品决策

- 正式学习环境为电脑端。首页、开始指南和演示页保留窄屏可读能力，方便从短视频进入后了解项目；游戏工作台在窄屏提示用户回到电脑继续。
- 第一版静态优先，只把进度保存在浏览器 `localStorage`，不建立账号、不调用 GitHub API，也不自动验证 GitHub 操作。
- 品牌、仓库地址、站点地址和赞助开关集中配置；发布前由维护者替换占位地址和自有素材。
- 真实毕业练习只在学习者自己的 Fork 内完成，不默认向上游仓库提交 Pull Request。

## 分阶段交付

### 1. 研究与骨架（已完成）

- 盘点 GitHub、Git、GitHub Desktop、Node.js 与 npm 官方资料。
- 定义课程范围、14 章学习路径、术语权重、界面覆盖和内容审校规则。
- 建立 Next.js App Router、严格 TypeScript、Tailwind、Zod、Vitest 与 Playwright 骨架。
- 完成 Design Read、视觉系统、架构与持久化文档。

### 2. 第零章（已完成）

- README 和 `docs/START_HERE.md` 承担从 GitHub 页面进入、登录、Fork、Clone 到运行项目的完整引导。
- 提供 GitHub Desktop、命令行和 Codespaces 三条路线，以及 Node.js、npm、localhost 和故障排查说明。

### 3. 可验证垂直切片（已完成）

- 建立任务工作台、答题反馈、术语侧栏、辅助模式、reducer 和版本化本地存档。
- 建立内容 schema、自动校验和覆盖报告。
- 验证仓库地图章节的正确答案、错误解释、重试与存档。

### 4. 完整课程（已完成）

- 完成第 0 至第 13 章主线、搜索词典、页面使用手册、P0 结业测试和 Fork 内毕业练习。
- 完成固定数据演示模式与本地分享卡。

### 5. 视觉与可用性（已完成）

- 统一落地页、工作台、文档页和结算页的品牌语言。
- 完成键盘焦点、减少动效、明暗配色和窄屏安全边界。

### 6. 发布验收（进行中）

- 执行内容校验、来源检查、类型检查、lint、单元测试、端到端测试和生产构建。
- 浏览器走查主页、工作台、词典、毕业任务、演示模式和键盘路径。
- 发布前仍需维护者替换仓库/站点占位地址；赞助保持关闭，直到提供真实二维码。

## 后续版本候选

- Next.js 的 React/a11y 插件链正式支持 ESLint 10 后，解除当前 ESLint 9.39.5 兼容锁定。
- 在不读取账号数据的前提下增加更多 GitHub Desktop 分支练习。
- 建立独立、带自动校验规则的社区毕业墙仓库。
- 定期核验 GitHub 界面截图与术语位置，避免界面更新导致指南过期。
