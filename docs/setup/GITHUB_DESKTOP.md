# 使用 GitHub Desktop

GitHub Desktop 是新手推荐路线，因为它把分支、修改、Commit、Push 和 Fetch 显示为可见界面。

1. 从 [desktop.github.com](https://desktop.github.com/) 安装。
2. 在 GitHub 网站 Fork 本项目。
3. 打开自己的 Fork，选择 Code → Open with GitHub Desktop。
4. 在 Local path 选择容易找到的文件夹，点击 Clone。
5. 在 Repository 菜单中选择 Show in Finder/Explorer 或 Open in Visual Studio Code。

Clone 后的本地修改只有 Commit 才进入本地历史，只有 Push 才出现在 GitHub 远程仓库。参考 [GitHub Desktop 官方文档](https://docs.github.com/en/desktop/adding-and-cloning-repositories/cloning-and-forking-repositories-from-github-desktop)。
