# GitHub 账号与安全

使用 [官方注册页](https://github.com/signup) 创建账号，或使用 [官方登录页](https://github.com/login) 登录。Username 是公开身份的一部分，也会出现在个人仓库 URL 中。

验证邮箱后，打开个人头像 → Settings → Password and authentication。GitHub 要求代码贡献者启用 2FA。Passkey 可以提供便捷且抗钓鱼的登录方式；Recovery codes 是账号恢复的一次性凭据，应保存到安全的密码管理器，不要发给任何教程或维护者。

本项目不会检查你的账号设置，也不会接收任何验证信息。账号安全以 [GitHub 官方 2FA 文档](https://docs.github.com/en/authentication/securing-your-account-with-two-factor-authentication-2fa/about-two-factor-authentication) 为准。
