# 使用 Codespaces

Codespaces 是 GitHub 托管的云端开发环境，通常提供浏览器版 VS Code、终端和端口转发。

1. 打开自己的 Fork。
2. 选择 Code → Codespaces。
3. 点击 Create codespace on main。
4. 等待终端准备完成，执行 `npm install` 和 `npm run dev`。
5. 打开自动转发的 3000 端口。

个人账户有每月计算与存储额度。达到限额后可能无法创建或启动需要计费的环境。完成后及时停止或删除不用的 codespace。参考 [官方 Quickstart](https://docs.github.com/en/codespaces/quickstart) 和 [额度说明](https://docs.github.com/en/codespaces/troubleshooting/troubleshooting-included-usage)。
