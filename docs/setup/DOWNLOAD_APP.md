# 在哪里下载，下载后怎么打开

README 的 macOS Apple 芯片按钮会直接下载成品；Windows x64 和 Intel Mac 尚未开放下载。**当前 Mac 包尚未经过 Apple 公证，首次启动可能被系统拦截。** 不要把 `Code → Download ZIP` 或 Release 附带的源码 ZIP 当成应用。版本和下载链接以 [README 下载区](../../README.md#下载桌面应用)为准。

推荐在电脑浏览器打开维护者提供的真实仓库地址：

```text
仓库首页（Repository）
  └─ 下方 README「下载桌面应用」
       ├─ macOS · Apple 芯片：M 系列 Mac
       ├─ Windows · x64：后续验收
       ├─ macOS · Intel：后续验收
       └─ 版本说明与校验值 → Release → Assets（成品文件列表）
```

这是一张位置示意，不是 GitHub 官方界面截图。GitHub 窄窗口中 Releases 入口可能移到页面下方；README 下载区优先。Windows ARM 和 Linux 只有经过实际验收并列入支持列表后才可以推荐。

## 打开成品

1. 看文件名中的系统与芯片类型，再看 Release 说明。Mac 在苹果菜单 → 关于本机查看芯片；Windows 在设置 → 系统 → 系统信息查看系统类型。
2. 下载 `.zip`，在下载文件夹里**先完整解压**。不要直接在压缩包内部运行。
3. Mac 打开解压文件夹里的 `GitHubStarterVillage.app`，可拖到“应用程序”。Windows 打开文件夹内的 `GitHubStarterVillage.exe`，不要单独移走 exe；它需要同目录的运行时文件。
4. 成品不需要 Node.js/npm/Git。入村引导 → 选择角色 → 江湖地图 → 第 0 章村口路标；断网可进行模拟学习，访问官方文档或在 GitHub 上进行 Fork 等真实操作需要网络。
5. macOS 提示“Apple 无法验证”时，按下一节操作；“已损坏”、检测到恶意软件或其他无法判断的告警请停止并联系维护者。

## Mac 提示“Apple 无法验证”，怎么打开

当前包只有本机临时签名，没有 Developer ID 正式签名和 Apple 公证；修复“已损坏”的签名问题不等于完成公证。此提示本身不能证明应用安全，也不等于 Apple 已检测到恶意软件。

仅在确认文件来自本项目 Release 且未遭篡改，并决定信任该应用后，严格按下面顺序操作：

1. 先点击警告框**右上角的“？”问号**，打开帮助并进入 Apple 官方提示。确认帮助页面地址是 `support.apple.com`，不要在第三方页面输入任何信息。
2. 返回警告框，点击“完成”，保留应用。
3. 打开苹果菜单 → **系统设置 → 隐私与安全性**。
4. 向下找到刚被阻止的 `GitHubStarterVillage`，点击 **仍要打开**。
5. 再次出现确认框时，点击 **打开**。如果系统要求，输入你自己的 Mac 登录密码；这只在 macOS 系统设置里输入，不要发给维护者，也不要输入游戏。
6. 启动成功后应看到入村引导。系统会记住该应用例外，后续可正常双击。

这是 Apple 提供的单个应用例外操作。[Apple 官方打开说明](https://support.apple.com/zh-cn/102445)，核验日期：2026-09-12。不要关闭 Gatekeeper、SmartScreen 或杀毒软件，也不要执行解除隔离命令；不要用以上步骤忽略“已损坏”或已检测到恶意软件的提示。如果没有“仍要打开”，请联系维护者并提供提示原文。

对于公开推广，首次启动仍要手工放行是未完成的分发体验。维护者需完成 Developer ID 签名、Apple 公证，并用最终包从 GitHub 重新下载实测；单纯换 ZIP、升级 Release 标签或改为 DMG 都不能代替这些步骤。

`Code → Download ZIP` 和 Release 自动附带的 `Source code (zip)` 都是源码，不是应用。安装成品也不等于 Fork 或 Clone；真实练习还要回到[从这里开始](../START_HERE.md)，取得自己 Fork 的源码。

## 可选：核对文件完整性

与同一 Release 页面中该附件显示的 SHA-256 比较完整的 64 位值，而不是只看开头；如果同时提供 `SHA256SUMS.txt`，也可以使用它。SHA-256 只证明文件是否一致，不证明发布者身份，也不代替 Apple 公证。

Mac：在 ZIP 所在目录打开终端，用 `shasum -a 256 文件名.zip`。Windows：在该文件夹打开 PowerShell，用 `Get-FileHash -Algorithm SHA256 .\文件名.zip`。不会使用终端的新手可以请维护者协助；不需要粘贴任何账号秘密。

## 存档、升级与卸载

行囊 → 导出当前进度，保存 JSON 到自己选择的位置。升级前先导出并关闭旧应用，再解压新版本到新的文件夹；不要把不同版本文件混放。启动后确认角色与任务仍在。异常时保留原始存档，通过导入恢复，不要反复重置。

删除/移至废纸篓应用文件夹即可移除便携应用，存档不会自动删除。若需清空学习记录，用应用内“重置样板”并确认；这会保存重置前备份。不要手工删除整个系统应用数据目录。
