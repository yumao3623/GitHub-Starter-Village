更新：2026-09-11。依据已批准 PRD 第 10 节。**目前真实参与者 0/3，招募与观察待执行；不得称为已验证适合小白。** 自动化测试和维护者走查另列，不充当参与者。

## 招募与环境

招募至少 3 名中文用户：第一次使用 GitHub，或过去一年仅偶尔浏览且没有独立完成过 Fork → Clone → PR。使用桌面浏览器或本地桌面壳，记录系统、窗口尺寸、浏览器版本和测试包 SHA。不收集姓名、账号、密码、Token、SSH 私钥、2FA 或恢复代码。

主持人先说明测试产品而非考核个人；允许停止。编号 P01–P03；只在获得同意后录屏，录屏文件由维护者管理，不提交包含个人信息的录像到公开仓库。主持人不能代操作或提前解释按钮位置。

## 不带答案的任务脚本

1. 从中文 README 找到可用入口，打开项目。候选包未发布时，主持人提供本地候选包并记录这一偏差。
2. 看完第一屏，选一位角色，进入地图。
3. 找到第 0 章并完成第一项任务。记录首次正确点击时间，是否在 30 秒内找到第一步。
4. 调查一个普通装饰或作一次错误投放，用自己的话说明反馈含义；继续重试或撤销，确认已有正确操作保留。
5. 完成第 0 章，返回地图。说出新开放的地点、主角去了哪里、获得什么。
6. 查阅武林宝典中的 Fork，解释它和 Clone 的差别，关闭宝典继续当前任务。
7. 进入自由探索，说明第 0 章之后是哪一章，以及演示是否会影响正式进度。
8. 自选一章继续体验；结束时复述一个英文动作及其刚刚造成的变化，记录兴趣评分 1–5 和原话。

最多一次中性提示：“请看当前目标和场景里的物件。”必须标记提示时间；不说按钮名称或正确答案。真实 GitHub 毕业练习只在本人官方环境自我检查，不能记录为自动验证。

## 验收门槛与问题分级

- 3/3 能独立找到第一步；至少 2/3 能在至多一次提示后完成任务。
- 不存在把模拟当成真实验证、向游戏输入秘密或向原仓库发送练习 PR 的安全误解。
- 错误操作不清空进度。
- P0：无法启动/完成、存档丢失、安全误导；P1：反复迷路、反馈不理解、宝典回不去；P2：文字、视觉和节奏偏好。
- 任一门槛失败：记录复现步骤、关联代码与修复证据，邀请原参与者回归；不得用开发者自动通关替代复测。
