# 抖音录屏演示

使用 /adventure-demo/，或桌面菜单「演示 → 录屏演示」。固定预置数据只存在内存中，不读写正式存档，不计有效用时。场景快跳按同一 reducer 重放正确操作，跳到第9章时第7/8章已完成，第9章仍等你操作。选择贡献链完成预设不等于真实用户完成，也不会授予 P0 掌握。

## 控制

自动生成内部镜头样片：先 `npm run desktop:build`，另开终端运行 `npm run desktop:preview`；再执行 `GSV_TEST_URL=http://127.0.0.1:3015 npm run demo:record`（Windows PowerShell 先设置对应环境变量）。输出在 `artifacts/phase-d/recording/`，是带固定数据标识的短 WebM，没有上传。生产预览不显示开发工具。

- 场景快跳：选角、迷雾地图、鉴宝、贡献链六章、四区域支线、贡献链完成留影。
- 复位当前镜头：清除该镜头后续演示改动，重新载入预设；保留当前所选人物。
- 一键重置演示：回到未选角色开场。不会清空正式游戏。
- 竖版录屏构图：760px 集中操作区，保留“固定数据”标记；适合桌面录屏裁切，不是手机产品支持。
- 江湖留影：导出1080×1920和1200×630 PNG，始终带演示标识。
- 实际拍摄优先使用桌面包；开发服务器会显示 Next.js 开发工具，不录入正式视频。

## 45秒脚本

| 时间 | 镜头 | 旁白 |
| --- | --- | --- |
| 0—5s | README 下载状态 | GitHub 看不懂？这是我做的本地学习游戏。公开下载尚未开放时明确说内部体验版。 |
| 5—10s | 选阿团进入地图 | 男侠客、女侠客，或练功的小猫，同一套课程。 |
| 10—20s | 鉴宝收集 Requirements/License 证据，错放 Stars | 不是背单词，先读资料，再判断项目。点错会解释为什么。 |
| 20—30s | 快跳分流竹林，建分支、查看 Diff | 每个改动都有去处；Commit 不是 Push。 |
| 30—38s | 百炼炉失败日志，修改草稿并重跑 | 检查通过，再决定合并。这里都是教学模拟。 |
| 38—45s | 快跳留影，导出卡片 | 最后回自己的 Fork 练一次。不是 GitHub 官方，也不会验证你的账号。 |

横屏建议1440×900或1920×1080；竖屏用集中构图裁切或竖版分享卡作为片尾。没有生成虚假用户通关影片。录屏不要包含个人目录、开发者工具、真实账号凭据。尚未上传 Release，不演出“点击下载成功”的假镜头；仓库占位符必须替换后才可用于公开宣传。
