# 抖音演示脚本

建议时长 35-50 秒。

1. “GitHub 全是英文，看不懂怎么办？”展示真实仓库 README 的中文入口。
2. “我做了一个 GitHub 新手村，第一关就是把它 Fork 和 Clone 下来。”快速切换第零章。
3. 展示工作台中 Pull Request 的“合并变更提案”解释。
4. 故意选错 Base/Compare，展示为什么错和立即重试。
5. 展示 Actions 的 Workflow → Job → Step → Checks 关系。
6. 展示毕业任务清单与本地分享卡。
7. “项目已经开源。Star 完全自愿，不影响通关。”

演示模式始终显示“固定演示数据”，不得暗示是真实用户成绩。
