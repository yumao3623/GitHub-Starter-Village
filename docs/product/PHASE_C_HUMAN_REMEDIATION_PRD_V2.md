## 参考原则

- [LearnGitBranching](https://github.com/pcottle/learnGitBranching)：即时可视反馈、撤销和短挑战。
- [Oh My Git](https://github.com/git-learning-game/oh-my-git)：单一知识目标承载独立关卡。
- [Git-Game](https://github.com/jakbrtz/Git-Game)：场景动作与状态保存。
- [papercade](https://github.com/anandparth/papercade)：纸张/手绘 UI、金币、卡牌翻面和减少动态处理。
- [html5-slot-machine](https://github.com/johakr/html5-slot-machine)：仅借鉴 Web Animation 的短回合节奏，不复制代码或博彩文案。
- 《侠客风云传》官方系统说明：养成、资源取舍与多路线带来重复游玩动机；本项目只借鉴“资源有明确用途、支线可回访”的结构，不涉及真实交易。

本支线是离线模拟，不接入支付、账号、广告或真实赌博；主线 GitHub 学习目标、凭据安全规则与独立项目声明保持不变。
