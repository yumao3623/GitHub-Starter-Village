## 支线规则

“百戏客栈 · 六骰聚财”是参考 Farkle 的单机取舍游戏。一轮三个回合，一次收取 5/10/20 文。每手选择能全部计分的骰子，留下后可收分或掷剩余骰；无得分组合则丢失本回合未收分数，已收分数保留。六骰全得分可重掷全部六骰。

总分 0 / 600 / 1200 / 2000 / 3200 对应返还本金的 0 / 0.5 / 1 / 2 / 4 倍及五个称号。固定倍率完全公开，不操控随机结果。所有数值来自规则状态机，界面不能提交“我赢了”的结果。第零至第四章完成后可付费入场；此前可免费试桌。银票仅买永久青玉桌与高手场，不改变概率。成绩卡由实际三回合分数生成，无自动联网分享。
