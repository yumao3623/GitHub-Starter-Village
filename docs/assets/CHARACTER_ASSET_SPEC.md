# 阶段 B：角色资产契约

2026-09-11。以用户批准的阶段 A 图集为唯一当前角色来源，不替换已有角色、不宣称已制作新的表情/动作帧。

## 可执行规范

入口：`src/content/characters/assets.ts`；使用方：`CharacterArt`。

每条资产包含稳定 ID、角色 ID、修订号、随包路径、图集尺寸、裁切矩形、来源记录、批准状态与一致性锚点。Zod 检查字段和裁切边界；内容测试检查资源与来源记录确实存在。

角色本体身份仍由 `src/content/characters/index.ts` 提供。地图、选角、鉴宝与结算通过同一解析器获取资产，不能硬写另一张人物图。男侠客、女侠客、小猫使用相同玩法，角色更换不修改关卡证据。

## 动作与回退

当前契约支持请求 `standing`、`portrait`、`walking`、`celebrating`。

当前只有已批准的站姿图。其余请求明确返回 `renderedPose: standing`、`fallback: true`，绝不拼入不同角色或伪称逐帧行走动画。地图上的移动是容器位置补间，不是已有角色骨骼动画。

后续新增动作时：

1. 先以阶段 A 原图锁定轮廓、发型/毛色、服装、随身物件和比例。
2. 增加同一角色的带版本资产条目及来源证明，不覆盖 v1 原图。
3. 扩展解析器中的 pose 映射；缺失时回退到同角色站姿。
4. 加入尺寸、裁切、实际文件、错误角色引用测试，以及地图/对话/结算的视觉对照。
5. 将说明与资源一起打包；第三方授权不能被项目 MIT 声明覆盖。

本阶段未新增生成图片、音效或第三方素材。原始生成说明见 [PHASE_A_ASSETS.md](PHASE_A_ASSETS.md)。
