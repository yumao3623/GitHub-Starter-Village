## 1. 保留什么，重做什么

审计基线：`30a78a2f9bc8e1e5bea7c08f799e6adde692a4c3`。现有山水 `public/world/jianghu-full-v1.png` 为主锚点：纸底、灰蓝远山、墨绿树林、赭色道路、矿物淡彩与细墨线。人物以现有青砚、陆行舟、沈知微、阿团为尺度与笔触参照，人物保持脚底落在场景地面、无白色卡底，不重做角色身份。

当前问题不是整幅山水不够复杂，而是同一画面内存在不同完成度：人物与山水为插画，棚架、炉具与案桌为几何线条，物件被统一装进现代方卡，正文继承系统黑体。因此优先统一接触最多的层：操作物、节点、按钮、正文、帮助与反馈。

设计推荐：**C 束带行囊秘籍 + B 封缄卷轴节点 + 马善政章名｜功能按钮 + 文楷正文**。大幅品牌短句可用志莽行书，英文用 Cormorant Garamond。C 已获选为后续默认图标方案，B 封缄卷轴继续作为地图节点方案。

Taste Skill 用于现有页面审计、具体设计判断、建立共同规则和实际尺寸检查。参数为变化 5 / 动效 6 / 密度 5。按用户要求，正式图标、器物、按钮底材用 Imagegen 生产；不使用营销页模板、通用线性图标或无语义角框代替。

## 2. 色彩、材料与光影

|角色|参考色|使用规则|
|---|---|---|
|宣纸底|`#f3eddd`|正文与阅读面板，避免纯白刺眼|
|主墨色|`#263d36`|主要正文，浅纸上清晰可读|
|松烟灰绿|`#425a4f`|木器、状态重点，不能把禁用与正常只靠绿色深浅区别|
|远山灰蓝|`#657f85`|远景、秘籍封面，不做科技蓝光|
|旧木赭色|`#9c825c`|案面、铜钱，减少金属高光|
|朱砂|`#924d3a`|印章、需处理的错误、极少量重点，不铺大面积鲜红|

主体器物是哑光木、旧纸、布绳、暗铜。光从画面左上方宽泛入射；轮廓靠墨线与材质，而非外发光。所有可接地器物以底部中央为锚点，不能让透明边距造成实际脚底悬浮。纸牌用正视或轻微俯视，背景中的舟车使用对应场景透视；不可用统一 3D 商品角度贴遍全图。

正文直接使用真实 `LXGW WenKai`，不只改变量名。缺字由同一文楷家族补齐；若发行范围文本出现缺字，先补授权字库再验收，不能默认回落为苹方或雅黑。系统菜单、外部 GitHub 页面、系统权限框不在应用字体控制范围。

字体文件与许可证均在本包内。Ma Shan Zheng、Zhi Mang Xing 与 Cormorant 从 Google Fonts 官方仓库获取，OFL 文本分别相邻保存。文楷采用 `lxgw-wenkai-webfont@1.7.0` 的常规与等宽分片，字体版本 v1.250；下载包 SHA-512 已与 npm 发布元数据一致，保留包 MIT 文件与字体 OFL 文件，两者不混同。只提取字体与静态 CSS，没有安装运行脚本或改应用依赖。

来源：[霞鹜文楷作者仓库](https://github.com/lxgw/LxgwWenKai)、[网页分片维护仓库](https://github.com/chawyehsu/lxgw-wenkai-webfont)、[马善政官方分发](https://github.com/google/fonts/tree/main/ofl/mashanzheng)、[志莽行书官方分发](https://github.com/google/fonts/tree/main/ofl/zhimangxing)、[Cormorant 官方分发](https://github.com/google/fonts/tree/main/ofl/cormorantgaramond)。文件原样随附许可；这些字体允许按各自 OFL 条件嵌入和再分发。

`typography-route-matrix.json` 列出当前 16 个路由｜加载｜错误文件，`review/sample.html` 提供 9 类全页样张。旧兼容页面的正文、按钮和表单继续在范围内。评审页可切换“v0.1 现代字体方向”比较同一排版的字形变化；这不是伪称取得了旧版同布局截图。真实旧截图另保留为 before-map、before-scene、before-lock、before-license。

## 4. 普通窗口版式

设计视口是 CSS 内容区，不能用 Retina 截图尺寸替代。样张统一分为：导航 76px、章标题与目标 88px、弹性场景区、操作反馈 88px、完整声明 76px。侧栏 240–285px；在 1024 宽度下优先精简文案和次级信息层级，不能将关键正文降到 14px 以下。

三档需检查 1440×900、1280×800、1024×720。正常视口核心目标、关键交互、反馈和主要操作同屏。长词条或完整日志可以在明确阅读区滚动，关闭与返回任务固定在其外。页面不靠 `overflow:hidden` 掩盖超出元素。

章节场景外框在同一视口下不因文案改变；盘面结构按玩法分工。第 0、8、10 章字体样张用于外框对照，并不把示意用的纸签阵列作为这些章最终盘面。最终连线、调度、叠签需依设计卡分别实现。地图始终完整等比展示所有地点的空间位置，不裁掉远端地点；富余区域给旁栏说明，不横向拉伸山水。

小于最小支持窗口或大幅文字放大时允许文档式滚动，保证可达性；这与桌面目标尺寸验收分开。弹层关闭要回到触发它的操作点；Esc 与键盘操作可用。

## 5. 品牌图标与地图节点

三份秘籍母图及各自 `.icns` 候选保留，不覆盖 v0.1。候选 A 强调封面和线装，可识别为书；候选 B 强调摊开的游记，候选 C 强调行旅束带。评审板比较 16、32、64、128px，64px 的 Dock 形态为**合成预览**。Mac Finder、Dock、应用切换器、重启与升级截图，必须在阶段 B 使用实际打包 `.app` 获取；不把本轮候选导出当成原生替换完成。

锁牌方案 A 为木座铜锁，B 为封缄卷轴。推荐 B 的纸卷与场景书卷语义一致，固定章号“四”经视觉校对。完整章号序列必须由配置生成，底材加授权字形导出并逐张核对；不复制“四”到其他章。地图对照只落第 4 章，其余地点用位置文字标记辅助空间检查，不声称整套节点已生产。

未解锁｜当前｜已完成｜解锁中的内容状态见 INTERACTION_SPEC。锁定原因、地点全名和章号有真实可访问文本；大图美观不能牺牲 52–72px 地图尺寸的可辨性。纸面图不可反射强光，也不覆盖整个建筑主体。

## 6. 按钮与道具状态规范

|状态|视觉表现|交互规则|
|---|---|---|
|默认|实物底材 + 清楚文字|底材不包含易变标签|
|悬停|材质小幅提亮；可有物体轻抬 1px|不突然长出装饰边框|
|键盘焦点|清楚的外侧焦点环，作为可访问辅助层|不能用审美理由取消焦点可见性|
|按下|下移 2px 或压缩纸面反馈|热区位置不跟随抖动|
|禁用|降低饱和度，明确原因文字|不可仅靠变灰猜原因|
|选中｜成功|章印或布签 + 文本状态|不能只换绿色|
|可恢复错误|朱砂说明 + 具体矛盾位置|保留已正确局面，允许撤回|

生成的复杂器物可做真实游戏对象，UI 按钮保持克制。首轮 button-base 附带松枝，第二轮被判过度装饰；编辑产物若出现实体棋盘格，列为失败重生，不纳入可用素材。生成大图不是免检通行证。

## 7. 图像生产与交接规范

按 `asset-ledger.json` 的 ID 生产；来源记录见 `generation-prompts.json`。每个候选或版本都有独立路径和哈希，记录采用、拒绝或待审阅，不能覆盖丢掉失败证据。原母图保留，另导出经用途裁边的透明 PNG/WebP。默认源图长边至少 1024，图标母图至少 1024²。

动画部件独立分层，按锚点、遮罩与层级驱动。动态文字和命令不画死进图片；固定章号采用可核验的合成。服装、植物、光影均需结合实际场景，不能把全幅山水打印到每个按钮、钱袋与纸签上。

## 8. 知识因果的核对来源

本轮复核影响代表性玩法的三处语义：Fetch 不会自动把远端内容合入自己的分支；`git add` 选择加入索引的当前内容；重新运行工作流保持该运行的 SHA/REF。对应设计分别落在第 8、10、12 章。[GitHub 远程变更说明](https://docs.github.com/en/get-started/using-git/getting-changes-from-a-remote-repository)、[Git add](https://git-scm.com/docs/git-add)、[GitHub 工作流重跑](https://docs.github.com/en/actions/how-tos/manage-workflow-runs/re-run-workflows-and-jobs)。其余词条沿用当前内容配置来源；不把本轮设计映射计数冒充逐词最新 UI 核验。
