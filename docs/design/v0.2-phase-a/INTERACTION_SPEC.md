# A 阶段 · 交互、经济与动效定稿

本文件规定 B、C 实现时必须可观察的行为。评审页的弹层与分镜是设计演示，不写正式存档、不执行 GitHub 操作、不构成可玩样板验收。

## 1. 导航与信息层级

入村说明 → 选角 → 地图 → 当前章节 → 局内结算 → 地图解锁 → 下一章。主导航固定为地图、宝典、行囊；帮助附着在当前目标旁。地图当前任务入口固定可见，章节的关键反馈和操作区固定可见。正文解释留在旁栏，长日志或证据打开专门阅读面板。

点击物件：先有看得清的选中反馈，再显示“这是何物｜可以做什么”；首次操作不要求玩家猜拖拽规则。Tab｜方向键移动可操作项，Enter 选择｜放置，Esc 关闭浮层，撤销回到最近可逆动作。鼠标拖放与点选两步操作等价，不强制精细操控。每章首步详见设计卡，不能复用三句泛泛口号。

帮助分级：第一层指出目标与规则；第二层指出哪份证据需比较；第三层演示一步。基础帮助始终免费；买线索只用于额外探索预演，不让付费虚拟资源成为理解规则的门槛。

## 2. 经济与路引规则

|对象|准确状态|操作与结果|
|---|---|---|
|铜钱｜银票|总值以“文”为整数单位；银票数量与零钱是持有形式|100 文铜钱换 1 张壹佰文银票；兑回相反，总财产不变|
|首次奖励|唯一键 `chapterId:first-clear`|首次有效完成 +10，保存成功后显示交接|
|迁移奖励|唯一键 `chapterId:first-transfer`|首次无提示完成新局面 +5；重玩不复发|
|额外线索|以具体局面、具体线索为唯一购买键|首次购入 −5；同局再查看不重复扣费|
|鉴宝彩头|每局唯一 roundId、投入、冻结额、结算状态|开局选择 0｜5｜10；先明示损失上限，再确认；不能负债|
|路引|签发章、已满足学习条件、核验章|按知识条件自动签发；钱不能购买通关条件|

鉴宝结算：初始余额 B、投入 s；确认后可用余额 B−s、冻结 s。举证正确，退回 s 并额外得 s，最终 B+s；错误只失去本轮 s，最终 B−s；退出未结算局或加载中断先恢复原局，不重新下注；主动取消尚未行动的局退回冻结。0 彩头任何结果不影响钱。通关是否成立取决于举证，独立于随机表现、余额和牌局盈亏。

防刷：章节与迁移奖励使用账本唯一事件；一个 roundId 最多一次 settlement。重新载入、回放、动画跳过或反复打开弹层不会加钱。导入完整存档替换为一个一致快照，不把两份账本相加。支持保留导出备份；异常不能静默清空余额或章进度。

### 资源节奏与可见用途

|节点|玩家看见与使用|
|---|---|
|第 0 章|领取钱袋、10 文、入谷路引；打开行囊看来源|
|第 1 章|门禁核验路引；核验是学习条件，不扣钱|
|第 3 章|第一次可选花 5 文看额外故障预演；拒绝购买也能学会、能过关|
|第 5 章|主线鉴宝局内选择无彩头或虚拟彩头，余额与投入清晰可见|
|第 7 章|签发贡献路引；第 8 章开始协作运输时核验|
|第 10 章|钱庄入口提供整笔兑换；一张银票面额壹佰文，购买时可自动找零并展示变化|
|第 12 章|结算整段旅程；真实赞助与资源完全分离|

可行性：不做额外挑战且不消费，第 9 章结束累计 100 文，能见到一次兑换；第 3 章买一次线索后，第 10 章结束 105 文，仍可兑换。只做主线总收入 130 文；全部首次迁移额外最多 65 文。主线任何必要动作收费均为 0，不需要刷钱拉长游玩。

v0.1 迁移：保留所有已完成章。按配置有效章 ID，每章首次补发 10 文并写迁移批次唯一事件；不推断老玩家完成了新迁移挑战，+5 必须新做。已有奖励账本时检测已发事件再补齐。旧进度缺失/损坏时解释并提供导入或新档选择，不自动覆盖可恢复备份。具体存储结构使用现有版本化 adapter，B、C 才编码。

## 3. 地图节点四态

|状态|可见样式|触发与语义|点击｜键盘|
|---|---|---|---|
|未解锁|完整封缄卷轴、闭锁、印在纸上的章号|前置知识条件未满足|解释具体原因，不静默无反应|
|当前可进入|开锁、绿色短签、地点名|前置条件已满足且尚未完成本章|进入章节；读出“第四章藏图阁，可进入”等名称|
|已完成|朱印替锁、章号保留|目标完成、奖励账本持久化成功|重访｜复习，不再次发首通奖|
|解锁中|路引核验 → 开锁 → 对应云团散开|保存成功且前置条件刚满足|不开放重复操作；允许跳过动画直达结果|

锁定原因和地点名是 DOM 真文字；固定章号图由配置导出并人工校对。当前 A 阶段样品只验证第 4 章构图。其他章不能复用错误“四”字。完整节点矩阵为配置章数 × 所需状态组合，但派生导出不算新增独立资产。

地图复用原有空间锚点，先保护全图地理关系；可微调地点牌偏移避免遮建筑，必须记录与锚点的关系。节点整体大小不能因解锁状态变化跳变。

## 4. 翻书与保存状态机

`playing → evaluating → saving → result → leavingChapter → mapRevealing → mapIdle → enteringChapter → playing`

1. evaluating 检查目标证据；saving 将章进度、奖励账本和解锁条件作为一致状态保存。
2. 保存失败进入可恢复错误，保留当前场景与重试｜导出操作；不得开始翻页或宣称领取完成。
3. 玩家在 result 选择回地图，当前场景做成前页；有页背、书脊、弯曲阴影和边缘遮挡。总长 0.6–1.2 秒，推荐 850ms，不使用单纯横移冒充翻书。
4. 地图打开后只揭开新获得访问权的区域，节点开锁与路径相连；玩家明确选择下一站后，再展开新章。
5. 关闭与刷新按已持久化状态恢复到 result 或 mapIdle，不能在半页层上永久卡住。动画没有发奖权，不能在 animationend 再 dispatch 领取奖励。
6. 连续点击做动作去重；无额外奖励。跳过转场立刻收敛到目标状态；减少动态效果用不超过 120ms 淡入或直接换页。

评审页仅提供可手动拖动的前页与背页结构分镜，明确标注平面旋转不能算正式曲面翻页。B 样板必须用生成纸页｜书脊资产实现并录正常速度视频。

## 5. 每章动效层级表

各章物件级位置和动作详见设计卡。以下冻结环境是否需要动，不要求每章都放环境循环。

|章|环境依据与位置|操作层｜触发|层级与遮挡|时长｜减少动态|
|---|---|---|---|---|
|地图|按真实水域遮罩；前后两层云团|解锁条件成立后局部散雾|山水 < 雾 < 节点 < 人物 < 信息层|雾 8–14s 微移，解锁 700ms；减少动态直接明示新地点|
|0|村口溪面，仅水域|正确连线亮路、旅人到达|路径在地表，人物在路径上，文字在最上层|280｜700ms；静态显路＋抵达标记|
|1|真实檐下灯笼|核验开闩、拒绝印落信|灯笼在门后，印盖在信件上|6s 微摆，160–200ms；静态状态|
|2|可不加循环环境|机器压印、装订、车轮沿轨迹|产物进出各机台真实开口|350–600ms；直接产物｜位置变化|
|3|炉口有火，服务未开时无火|接头、错误日志展开|火限炉口，日志不遮必要操作|240ms、火势状态；静态火态＋文字|
|4|室内书架，无叶与水纹|取册、翻牌、落托盘|按真实遮挡关系绘制层叠|160–280ms；直接升层｜落位|
|5|室外摊幡，有支杆|证据翻开、彩头移动|筹码只在桌与钱袋之间|220｜400ms；显示账目变化|
|6|飞行出发台与落台明确|起飞、来信落槽、规则调整|信件不挡当前阅读笺；全流可暂停|飞行 1.2s；静态队列可选|
|7|檐下悬挂灯笼|拼片归位、钉案卷、封安全信|拼图在案纸上，告示不遮目标|180–240ms；即时归位|
|8|桥下水域，不能上岸|Fetch 信使、Push 货车、回执|桥板遮住桥下水，货车在桥上|500–750ms；站点状态直显|
|9|仅实际竹冠附近|分支指针、差异签、路径切换|分支指针不等于移动整座仓库|3–5s 微摆，300ms 路径；无环境动画|
|10|室内桌面，无环境粒子|取签、暂存、封卷、远程回执|可读差异层最高；被盖签不可点|120–420ms；逐态直接变化|
|11|议事厅，灯与帘如真实存在再做|意见从席位送来、修订、压印|意见不覆盖编辑区；对应 NPC 来源|240–300ms；直显意见与批准态|
|12|炉口、烟口各有独立遮罩|失败收火、重跑、产物推出|火与烟位于正确器具口；不遮日志|200–500ms；文字＋静态火态|

图层性能预算：先合并静止景物；环境最多 3 类同时循环、不可见页停播；优先 transform/opacity 与局部遮罩，不让整幅 4K 背景每帧重绘。目标普通 Mac 连续交互平稳，具体帧率与内存需 B、C 真实测量；A 不宣称通过性能测试。

## 6. 阶段 B 的交接条件

美术选择与规则已可审查。用户确认这些定稿方向后，B 的范围是第 0、8、10 章完整可玩样板、一次真实的钱袋使用、一次完整翻书转场，以及打包原生图标验证。用正式生成资源接入这些代表性样板；遇到美术不匹配需回到参考与合成，不得降级为线条占位。

全线扩展、完整字库接入、原生包、性能、新手试玩、真实二维码分别按原 PRD 的 C、D、E 阶段验收。本轮没有发布授权。
