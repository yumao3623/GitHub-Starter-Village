# 无障碍要求

- 遵循 WCAG 2.2 AA；正文对比度至少 4.5:1，大字号至少 3:1。
- 所有交互可以使用键盘，焦点顺序与视觉顺序一致。
- 任务选择使用真实 Button，辅助模式使用带标签的 Select。
- 正误反馈使用 `aria-live="polite"`，不能只靠颜色表达。
- 动画遵循 `prefers-reduced-motion`；没有倒计时或失败清零。
- 首页、第零章和演示预览在 390px 宽度下没有横向页面溢出；工作台窄屏明确建议回到电脑，不把手机端列为完整通关环境。
- 外链标明会前往 GitHub 官方网站；安全提示不隐藏在 Tooltip 中。
