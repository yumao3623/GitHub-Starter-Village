# 云溪谷页游设计方向

更新：2026-09-11。依据 NEW_TASK_HANDOFF_PRD v1.1；以桌面浏览器和本地桌面壳为目标，1024px 宽仍可操作，390px 不作为主线验收设备。

## Design Read

中文 GitHub 初学者进入一张可操作的武侠画卷：先由引导建立真实/模拟边界，再选择角色，沿十三处地点学习。画卷是主视觉，菜单服务于任务。Taste Skill 用于反模板化、原创品牌语言、单一图标族、明确状态与键盘操作；不让营销页面模式决定游戏工作台。

## 同源视觉

- 纸底 `#f3eddd`、墨字 `#213d37`、玉色操作 `#2c6b58`；赭色仅用于印章、灯火和错误提示，不做紫色渐变或玻璃卡片。
- 标题使用系统宋体，正文使用系统中文无衬线，命令用等宽字体；没有新下载的字体或第三方游戏资产。
- Phosphor 是唯一 UI 图标族；原创牌楼、书架、马车、灯笼、炉火和青砚作为场景物件。图标旁保留文字，不借用 GitHub Logo/Octocat。
- 三角色共 12 个独立 RGBA 文件，420×640 画布，足底 y=632；小猫保持较小体型。`CharacterPlacement` 定义地面、缩放、脚偏移、接触阴影，不逐页用负 margin 修脚。

## 产品画布

启动页：画卷右侧留景、左侧说明本地模拟与真实学习路线。选角页：左侧文案和当前选择，右侧三个完整角色，无相邻图集碎片。未选择角色时不能进入地图。

地图：完整原创江湖图铺满，主线由左到右，地点上下随地形分布；锁定区域只有不可操作轮廓。地点印章、剧情道具和下一站提示记录进度。SVG 道路与角色 motion path 共用锚点，按路径前进；窗口尺寸变化重算运动坐标。

章节：全宽局部地图 + 底部任务台。轻量 HUD 包含章节、当前目标和进度；场景放主角、青砚、可交互机关和状态；底部左侧剧情与工具，右侧操作/错误原因/动作证据/奖励。每一阶段只呈现当前物件。章节内不提供其它章节跳转菜单。

13 章的 `parentMapRegionId`、`cameraStart`、`walkableGround`、`npcAnchors`、`interactiveHotspots`、`returnMapReward` 统一声明，镜头读取对应大图区域。独立的牌楼/灯笼/机器/火槽/书架/摊位/信箱/告示/马车/竹径/编辑台/评审席/炉火与操作状态构成局部地图，而不是替换背景标题。

## 线装宝典

居中独立阅读面，深玉书脊、纸色封面与目录、分卷“入村/仓库/协作/发布”；章节索引只筛词，不跳主线。阅读面包含英文、中文、非字面理解、动作例子、易混淆概念与官方来源；书签和待复习独立保存。上一条/下一条/回到任务留在阅读面底部。原生 dialog 限制焦点范围，Esc 关闭后返回触发按钮，原章节状态保留。

## 交互和动效

拖放都有“选择物件 → 选择目标”的键盘等价操作；编辑使用真正 textarea；通知风铃使用原生 range。阶段变化聚焦新任务标题，错误保留成功记录，撤销/重试保留已取得的地图奖励。场景方向键移动主角。

动效服务于状态：路牌连线、灯火、断线/恢复、货物运送、工作区到远程的状态条、评审意见、炉火检查；完成后盖印、揭雾、沿路移动。用户设置或系统 reduced motion 将动效立即归结为最终状态，文本反馈和解锁仍保留。没有倒计时、体力、付费或强制社交。
