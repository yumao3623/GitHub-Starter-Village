# 从这里开始：第零章

如果你第一次打开 GitHub，请按顺序完成，不需要一次记住所有英文。

## 你的目标

1. 只在 GitHub 官方网站注册或登录。
2. 把项目 Fork 到自己的账号。
3. 用 GitHub Desktop、命令行或 Codespaces 获取项目。
4. 安装 Node.js 和依赖。
5. 在浏览器打开 localhost。

## 安全检查

地址栏必须是 `github.com` 才输入 GitHub 登录信息。本项目不会索要密码、PAT、SSH 私钥、2FA 代码或 Recovery codes。任何教程要求粘贴这些信息时都应停止。

## 当前页面的六个路标

Repository 是项目空间；README 是入口说明；Public 是可见性；Star 是可选收藏；Fork 在你的账号下创建副本；绿色 Code 按钮打开 Clone、Codespaces 与 ZIP 菜单。

## 推荐路线

登录 GitHub → Fork 本仓库 → 打开自己账号下的 Fork → Code → Open with GitHub Desktop → Clone → 打开项目目录 → 安装 Node.js LTS → `npm install` → `npm run dev` → 打开 `http://localhost:3000`。
