# 毕业练习目录

这里用于你在**自己的 Fork** 中完成真实练习。请不要为了毕业向原项目仓库提交无意义的 Pull Request。

1. 从自己 Fork 的 `main` 创建新分支，例如 `practice/你的用户名`。
2. 复制 `practice/example.md`，改名为 `practice/你的用户名.md`。
3. 填写其中的检查清单，不要写邮箱、密码、令牌或其他隐私信息。
4. Commit 并 Push 这个分支。
5. 在自己的 Fork 内创建 Pull Request，检查 Files changed 后合并到自己的 `main`。
6. 删除练习分支。

游戏内 `/capstone` 页面提供逐步清单。项目不会读取你的 GitHub 账号，也不会声称自动验证结果。
